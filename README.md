# OneNotify (Android prototype)

แสดงการแจ้งเตือนที่ยังค้างอยู่จาก LINE, Messenger, WhatsApp และ WhatsApp Business ในรายการเดียว แตะรายการเพื่อส่ง `contentIntent` ของการแจ้งเตือนกลับไปเปิดแอปต้นทาง หน้าหลักปรับตามต้นแบบ Stitch ของผู้ใช้: ส่วนหัว OneNotify, ภาพรวม, ค้นหา, ตัวกรองแอป, การ์ดข้อความ และเมนูล่าง

## เริ่มใช้งาน

1. เปิดโฟลเดอร์นี้ด้วย Android Studio และรอ Gradle Sync (AGP 8.13.2, JDK 17, Android SDK 35) หรือรัน `gradlew.bat :app:assembleDebug`
2. Run แอปบน Android 8.0 ขึ้นไป
3. แตะ **ตั้งค่าสิทธิ์อ่านการแจ้งเตือน** แล้วอนุญาต One Inbox
4. เปิดการแจ้งเตือนและการแสดงตัวอย่างข้อความในแอปต้นทาง

ไฟล์ APK สำหรับทดสอบอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk` (คอมไพล์ผ่านบน Windows วันที่ 18 พฤศจิกายน 2026)

## ทดสอบบนมือถือจำลอง

เครื่องนี้มี Android Emulator ชื่อ `OneNotify_Pixel_7` (Android 15 / API 35) ติดตั้งแอปและเปิดหน้าหลักแล้ว ภาพหน้าจอจริงอยู่ที่ `emulator-preview.png` หากต้องการเปิดอีกครั้ง ใช้ `emulator -avd OneNotify_Pixel_7` แล้วรัน `adb shell am start -n com.allin1.oneinbox/.MainActivity`

## ขอบเขตและความเป็นส่วนตัว

- แสดงเฉพาะการแจ้งเตือนที่ยังค้างอยู่ ไม่ดึงประวัติแชตและไม่เก็บข้อความลงฐานข้อมูลหรือส่งขึ้นเซิร์ฟเวอร์
- เนื้อหาที่ซ่อนในการแจ้งเตือนจะไม่ปรากฏในแอปนี้
- การแตะเปิดใช้ intent ที่แอปต้นทางแนบมา จึงขึ้นอยู่กับพฤติกรรมของแอปนั้น
- หน้าแชทด่วนเป็นทางลัดกลับไปยังกล่องข้อความ ไม่มีการตอบใน OneNotify; รุ่นนี้ยังไม่มี AI วิเคราะห์ความเร่งด่วนหรือปุ่มอ่านทั้งหมด เพราะสถานะเหล่านั้นไม่สามารถสั่งให้ตรงกับแชตต้นทางผ่าน Notification Listener ได้
- การอนุญาต Notification access ทำให้ Android ให้สิทธิ์อ่านการแจ้งเตือนจากทุกแอป แม้ One Inbox จะกรองแสดงเพียงสี่ package ข้างต้น ผู้ใช้ควรถอนสิทธิ์เมื่อเลิกใช้งาน
